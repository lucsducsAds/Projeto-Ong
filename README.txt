# Instituto Viver Melhor — SPA

Versão adaptada para a Experiência Prática III.

- Uma única página HTML.
- Navegação por hash (#inicio, #projetos, #cadastro).
- Conteúdo inserido dinamicamente no elemento #app.
- Projetos armazenados em JavaScript e gerados com Template Literals + map().
- Categorias e listas internas também são geradas com map().
- Formulário preparado após a renderização da rota.
- Menu responsivo e mensagens de feedback preservados.

html/index.html
css/style.css
js/app.js
js/menu.js
